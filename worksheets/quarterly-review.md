# Quarterly Security Review
*30 minutes, four times a year. Set a recurring calendar event.*

**Review date:** _____________ &nbsp;&nbsp; **Completed by:** _____________

## Credentials & Access

- [ ] Any breach notifications since last review? If yes: rotate affected passwords, check for reuse
- [ ] Check [haveibeenpwned.com](https://haveibeenpwned.com) for new breaches on all email addresses
- [ ] Any new accounts created since last review? Added to inventory?
- [ ] Any dormant accounts to delete?
- [ ] Password manager master password: still strong? Still exclusively memorized (not written down somewhere insecure)?
- [ ] Hardware keys: both accounted for? (Primary + backup)
- [ ] Backup codes: still stored and accessible for all Hub accounts?
- [ ] Any Hub accounts still on SMS 2FA? Target for upgrade?
- [ ] Any accounts now offering passkeys that you haven't adopted?

## Devices & Network

- [ ] Run Fing scan on home network — any unfamiliar devices?
- [ ] Router firmware: checked for updates?
- [ ] Any devices needing OS updates that weren't auto-applied?
- [ ] Any new IoT devices added? On guest network?
- [ ] Emergency Access Kit: still accurate? Any changes to accounts, keys, or recovery methods?
- [ ] Any devices to retire, wipe, or remove from inventory?

## Identity & Social Surface

- [ ] Data broker re-check: spot-check top 5 brokers for your name (re-list after 90 days is common)
- [ ] Any automated removal service reports reviewed?
- [ ] Social media privacy settings: any platform changes since last review that reset defaults?
- [ ] Any new photos or posts with location data to review?
- [ ] Credit monitoring alerts this quarter? (If enrolled)

## Recovery & Planning

- [ ] Any major life changes since last review? (see trigger list below)
- [ ] Playbook still accurate? Phone numbers current? Recovery contacts current?
- [ ] Any family members to check in with about their security posture?

**Trigger list — re-audit when any of these happen:**
- New job or leaving a job
- New relationship or separation
- Move to a new address
- Death in family
- New devices for kids
- Significant new financial account or asset
