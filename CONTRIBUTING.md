# Contributing to Project Chrysalis

This is a community-maintained public resource. All contributions are welcome.

## What We Need
- Guide content for any of the eight modules
- Real-world breach scenarios (anonymized) for the scenarios section
- Tool reviews and recommendations
- Translations
- Corrections, simplifications, and clarity improvements
- Worksheets and printable formats
- Partner outreach and relationship contacts
- Accessibility improvements

## Standards
- Write for a non-technical adult as the primary audience
- Technical depth is welcome in clearly marked sections or appendices
- No vendor promotion without disclosure, tool recommendations must be justified
- Scenarios and examples should be realistic, not theoretical
- Keep language honest: don't minimize real threats or manufacture fear
- **Privacy first:** Never include content that encourages users to share sensitive information with untrusted services. Every agent prompt must include clear privacy guidance.

## Process
1. Open an issue before large contributions to align on scope
2. Fork, branch, PR
3. One module or topic per PR

## Code of Conduct
This project is a public service resource. Be excellent to each other.
